# Original source snapshot

These six Python scripts are preserved unchanged from the supplied `Drone_GPS_Simulation.zip`. Its `requirements.txt` was empty. Its embedded Git history is not published.

The archived pipeline contains hard-coded local paths, mismatched PX4 GNSS fields that silently become zeros, and a 20-second label / 25-second figure inconsistency. Use the portable implementation in the top-level `src/pipeline/` for the documented workflows. This snapshot is retained for provenance.
